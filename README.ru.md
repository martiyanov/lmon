# lmon — монитор компьютера в терминале

**[English](README.md)** · Русский

Это маленькая программа: запускаешь — и в окне терминала раз в секунду
появляется строка с главными показателями компьютера. Зелёное — всё
хорошо, жёлтое — внимание, красное — плохо. Можно не читать цифры, а
просто коситься на цвет.

Заголовок закреплён внизу окна, значения стекаются над ним; подпись
каждой колонки залита цветом её текущего состояния — статус виден
по нижней ленте даже в окне высотой 2 строки:

```
 12   2   1  62  55°      ← значения стекаются вверх
 11   2   1  63  55°
118   3   1  63  56°      ← интернет «моргнул»: шлюз в норме, виноват канал
NET  GW AVG MEM  C°       ← закреплённый заголовок, подложка = цвет состояния
```

Работает на macOS, Windows 10+ и Linux. Одна программа, ничего
дополнительного ставить не нужно (кроме температуры на macOS — см. FAQ).

## Установка

### macOS

1. Открой программу «Терминал»: нажми `Cmd + Пробел`, набери
   «Терминал» (или Terminal) и нажми Enter.
2. Скопируй в него эти две команды (по одной; после каждой нажми Enter):

```sh
curl -fsSL https://github.com/martiyanov/lmon/releases/latest/download/lmon_darwin_arm64.tar.gz | tar -xz
```

```sh
sudo mv lmon /usr/local/bin/
```

Вторая команда спросит пароль от твоего мака — набери его и нажми Enter.
При наборе пароль не показывается, это нормально.

> Если у тебя старый мак с процессором Intel, возьми в первой команде
> `lmon_darwin_amd64.tar.gz` вместо `lmon_darwin_arm64.tar.gz`.

Если стоит Homebrew, достаточно одной команды:

```sh
brew install martiyanov/tap/lmon
```

### Windows 10/11

1. Открой PowerShell: нажми правой кнопкой по кнопке «Пуск» →
   «Терминал» (или «Windows PowerShell»).
2. Скопируй по очереди:

```powershell
curl.exe -fsSL -o lmon.zip https://github.com/martiyanov/lmon/releases/latest/download/lmon_windows_amd64.zip
```

```powershell
Expand-Archive lmon.zip
Move-Item lmon\lmon.exe "$env:LOCALAPPDATA\Microsoft\WindowsApps" -Force
```

3. Набери `lmon` и нажми Enter.

> Если Windows покажет синее окно SmartScreen («Система защитила ваш
> компьютер») — это стандартное предупреждение про незнакомые
> программы без цифровой подписи. Нажми «Подробнее» → «Выполнить в
> любом случае». Код lmon открыт: [github.com/martiyanov/lmon](https://github.com/martiyanov/lmon).

### Linux

Debian / Ubuntu:

```sh
curl -fsSLO https://github.com/martiyanov/lmon/releases/latest/download/lmon_amd64.deb
sudo dpkg -i lmon_amd64.deb
```

Любой другой дистрибутив:

```sh
curl -fsSL https://github.com/martiyanov/lmon/releases/latest/download/lmon_linux_amd64.tar.gz | tar -xz
sudo mv lmon /usr/local/bin/
```

## Проверка: всё ли установилось

Набери:

```sh
lmon 5
```

Должно появиться 5 строк с числами — значит, работает. Полная
инструкция по-русски — всегда доступна командой:

```sh
lmon help
```

## Как пользоваться

| Команда | Что делает |
|---------|-----------|
| `lmon` | показывает значения бесконечно, выход — `Ctrl + C` |
| `lmon 20` | выведет 20 строк и сам закроется |
| `lmon -b` | режим цветных квадратов: цифр нет, только цвета |
| `lmon --hybrid` | цифры на цветной подложке — и цвет, и точные значения |
| `lmon --cpu --swap` | добавить колонки: процессор, swap |
| `lmon --disk --batt` | …диск и батарея (всё можно сочетать) |
| `lmon --cols TNGC` | свой набор и порядок колонок |
| `lmon --gpu` | добавить колонку загрузки видеокарты |
| `lmon --once` | одна строка значений — для tmux-строки статуса |
| `lmon --target fe80::1%en0` | IPv6: литерал, можно link-local с зоной |
| `lmon help` | справка на русском |

Пример: следить за ноутбуком «боком зрения», цветными квадратами:

```sh
lmon -b --cpu --swap --disk --batt
```

### Что означают колонки

Заголовки трёхбуквенные и ровно по ширине значений: `NET` — пинг до
интернета (мс), `GW` — пинг до роутера (мс), `AVG` — загрузка системы,
`MEM` — память (%), `C°` — температура процессора. По флагам
добавляются: `CPU` — процессор, `IOW` — ожидание диска (только Linux),
`SWP` — swap, `DSK` — диск, `BAT` — батарея, `GPU` — загрузка видеокарты
(--gpu; на macOS без sudo, на Windows — «·»), `G°` — температура GPU
(--gputemp; только Linux, на macOS/Windows нужны права админа — честное «·»). Набор и порядок — любой:
`lmon --cols TNGC`. Точка `·` — такого датчика в системе нет,
`999` — хост не отвечает, `+++` — число не влезло в колонку.

Точные пороги цветов — в `lmon help`. Коротко о плохих цифрах:

- `N` и `G` красные вместе — плохо у тебя дома: Wi-Fi, роутер, кабель.
  Только `N` — плохо у провайдера.
- `MEM` красный и `SWP` растёт — кончается память, компьютер тормозит.
- `CPU` около 100 долго — какую-то программу стоит закрыть.
- `C°` выше 80–90 — перегрев.
- `U%` выше 90 — забит диск.
- `999` — хост не отвечает, `·` — такого датчика в системе нет
  (например, температура на Windows).

## FAQ

**Спросил пароль при установке (`sudo`) — это что?**
Это твой пароль от учётной записи. Он не отображается при вводе — так
устроено. Ставим программу в системную папку, поэтому нужен пароль.

**«command not found: lmon» после установки.**
Закрой терминал и открой заново. Не помогло — выполни установку ещё
раз и посмотри, не было ли красных ошибок.

**Хочу температуру процессора на macOS.**
Поставь маленькую утилиту smctemp — без неё колонка `TMP` показывает «·».
Как поставить: https://github.com/holtmann/osx/tree/master/smctemp

**На Windows колонки L и T показывают точку.**
Так и задумано: в Windows нет показателей load average и температуры
без прав администратора. Честная точка лучше выдуманного числа.

**Первая строка подозрительно большая.**
Первая строка всегда немного врёт: Wi-Fi «просыпается». Со второй —
честные числа.

## Как удалить

macOS / Linux:

```sh
sudo rm /usr/local/bin/lmon        # ставили curl-ом
brew uninstall martiyanov/tap/lmon # ставили brew-ом
```

Windows: удали файл `lmon.exe` из папки
`C:\Users\<имя>\AppData\Local\Microsoft\WindowsApps`.
