## Продукт / UI

- [x] **RUN: цвет по числу ядер** *(исследование проведено 31.10.2026)*.
  Пороги сейчас фиксированные (зелёный ≤4, жёлтый ≤8) — на MacBook Pro
  M1 Pro (8 ядер) load 4–6 держится постоянно и вечно жёлтый, хотя это
  0.5–0.75 очереди на ядро, то есть норма. Load average — длина очереди,
  а не «% загрузки»: load = числу ядер означает «все ядра заняты».
  Практика мониторинга (Nagios `check_load -r`, ServerFault): нормировать
  на ядра; предупреждающий порог 0.7–1.0×ядер, критический 1.5–2×ядер.
  Решение попроще: значение показывать как есть (целым), а цвет считать
  по load/ядер — зелёный ≤ числа ядер, жёлтый ≤ 2×ядер, красный выше.
  Число ядер: `runtime.NumCPU()` (на Linux учитывает affinity — важно
  в контейнерах). Попутно обновить таблицу порогов в help/README.
- [x] **Пороги цвета — настраиваемые.** На слабом/мобильном интернете
  100–200 мс — нормальная работа, а статичные пороги NET (50/150)
  дают вечный жёлтый. Варианты: флаги вида `--net 150,400`, единый
  `--thresholds NET=150,400,...`, переменная LMON_THRESHOLDS, конфиг
  `~/.config/lmon.conf`, пресет «мобильный интернет» (`--mobile`).
  Делать после решения по RUN — единый механизм порогов на всё.
- [x] **Температура: без градуса в цифрах.** Заголовок колонки уже
  показывает `C°` — в самих значениях градус не повторять: сейчас
  рисуется `59°`, должно быть просто `59` (в help и на сайте тоже,
  где упоминается формат значений).
- [x] **Выравнивание заголовков колонок.** Сейчас из 12 заголовков три —
  двухбуквенные с ведущим пробелом: `" GW"`, `" C°"`, `" G°"` — прижаты
  вправо и выглядят смещёнными (особенно GW и G°; C° читается нормально,
  градус — узкий приподнятый глиф). Варианты: сделать GW трёхбуквенным
  (GTW?), левое выравнивание двухбуквенных, или пересмотреть подписи всех
  колонок разом на «красиво трёхбуквенно». Заодно глянуть всю ленту
  целиком: подписи и значения в блочном/гибридном режимах.
- [ ] **Сайт: кнопка «убрать в угол» в живой демке** — терминал демо
  сжимается до ширины индикаторов и парковывается в угол, как в ролике.
- [ ] **Сайт: встроить видео-демо 15с** (`media/lmon-demo-corner.mp4`)
  секцией под живой демкой; для Pages положить копию в `docs/`.
