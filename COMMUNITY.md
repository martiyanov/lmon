# Сообщество lmon · lmon community

lmon — маленькая утилита, поэтому сообщество тоже маленькое и без бюрократии.
Общаемся **на русском и английском**; ответы и решения живут в GitHub Discussions,
чтобы их можно было найти через поиск и не терять в чатах.

## Где общаться / Where to talk

| Куда | Для чего |
|---|---|
| [GitHub Discussions](https://github.com/martiyanov/lmon/discussions) | **каноническое место**: идеи, вопросы, показы настроек. Поиск, ссылки, ответы |
| `Ideas / Идеи` | одна тема = одна идея; шаблон подскажет, что приложить |
| `Q&A / Вопросы` | установка, настройка, странные значения; версия + ОС + вывод `lmon --once` |
| `Show and tell / Покажи` | tmux, скрипты, цвета, интеграции |
| `Announcements / Анонсы` | релизы и важные изменения |
| Matrix / Telegram | быстрый чат; ссылки появятся здесь после запуска комнаты/канала. **Ответы всё равно дублируем в Discussions** |

## Правила / Rules

- Уважение к людям и их времени; критика — по делу, с примером.
- Перед созданием темы — поиск по Discussions и Issues.
- Не публикуйте токены, пароли, приватные адреса, чужие данные.
- Не превращайте темы в чат: для «просто поболтать» есть General/чат.
- Уязвимости — **не в публичные темы**, а приватно:
  [Security → Report a vulnerability](https://github.com/martiyanov/lmon/security/advisories/new).
- Язык — русский или английский; можно оба. Тег `ru`/`en` приветствуется.

## Как идея становится фичей / From idea to release

1. Тема в `Ideas`, реакции и обсуждение.
2. Мейнтейнер или агент-триаж проверяет дубли и переносит идею в
   [BACKLOG.md](BACKLOG.md) либо создаёт issue с меткой `idea`.
3. Реализация → релиз; в теме появляется ссылка на issue/релиз, тема закрывается.

Метки issues: `idea`, `enhancement`, `bug`, `documentation`, `question`,
`good first issue`. Если хотите помочь — начинайте с `good first issue`.

## Модерация и ожидания / Moderation

- Мейнтейнер — [@martiyanov](https://github.com/martiyanov).
- Отвечаем по возможности в течение нескольких дней; это хобби-проект, не 24/7.
- Спам, оскорбления и офтоп удаляются; злостные нарушения — блокировка.
- Жалобы и спорные решения — в личные сообщения мейнтейнеру.

## Автоматизация идей

Периодически агент проходит по новым темам `Ideas` и `Q&A`, проверяет дубли
с `BACKLOG.md`/issues, делает дайджест и черновики задач. Решения по-прежнему
принимает мейнтейнер — автоматика не создаёт релизы и не меняет код без ревью.

## Код поведения / Code of conduct

Коротко: будьте нормальными людьми. Проект следует духу
[Contributor Covenant](https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/):
никакой дискриминации, травли и публикации личных данных.
